# Тестирование модального окна и интеграции с API

## Что создано:

### 1. **Модальное окно ProductModal**
- Отображает полную информацию о товаре
- Показывает цену со скидкой и оригинальную цену
- Включает все поля из базы данных:
  - Название
  - Краткое и полное описание
  - Материалы
  - Сроки изготовления
  - Цена и скидка

### 2. **Интеграция с API**
- Хуки `useProducts` и `useCategories` для работы с данными
- Обновленные компоненты карточек с поддержкой модального окна
- Загрузка данных из базы данных вместо моков

### 3. **Обновленные компоненты**
- `GranitCatalogCard` - теперь принимает объект `product` и открывает модальное окно
- `DetailsButton` - добавлен обработчик `onClick`
- `GranitCatalogCards` - использует данные из API
- `CategoryCards` - новый компонент для отображения категорий

## Как протестировать:

### 1. **Настройте базу данных**
```bash
# Создайте .env.local с вашей строкой подключения
DATABASE_URL=postgresql://username:password@hostname:port/database?sslmode=require

# Выполните SQL скрипты в Neon Console
# database/schema.sql - создание таблиц
# database/seed.sql - заполнение данными
```

### 2. **Запустите проект**
```bash
npm run dev
```

### 3. **Проверьте функциональность**
- Откройте главную страницу - должны загрузиться категории из БД
- Перейдите в каталог - должны загрузиться товары из БД
- Нажмите "Детали" на любой карточке товара - должно открыться модальное окно
- В модальном окне проверьте отображение всех полей товара

### 4. **API эндпоинты для тестирования**
- `GET /api/categories` - список категорий
- `GET /api/products` - список товаров
- `GET /api/contact` - контактная информация

## Возможные проблемы:

1. **Ошибка подключения к БД** - проверьте DATABASE_URL
2. **Пустые данные** - убедитесь, что выполнили seed.sql
3. **Модальное окно не открывается** - проверьте, что передается объект `product`
4. **Ошибки TypeScript** - убедитесь, что установлены типы `@types/pg`
