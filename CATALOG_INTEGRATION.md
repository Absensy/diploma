### 1. **Обновлен компонент GranitOurCatalog**

### 2. **Обновлен MonumentCategoryCard**
- Добавлена поддержка цены со скидкой

### 3. **Обновлена главная страница**

## 🔄 Логика отображения цен:

```typescript
// Если есть скидка:
if (discounted_price) {
  // Показываем цену со скидкой красным цветом
  // Оригинальную цену зачеркнутой серым цветом
} else {
  // Показываем обычную цену
}
```

## 📊 Структура данных:

### Category (из Prisma):
```typescript
{
  id: number
  name: string
  price_from: Decimal
  photo: string
  discount?: number
  discounted_price?: Decimal
  created_at: DateTime
  updated_at: DateTime
}
```

### MonumentCategoryCard Props:
```typescript
{
  name: string
  price: number (price_from или discounted_price)
  image: string (photo)
  discount?: number
  discounted_price?: number
}
```
