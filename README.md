# Гранит Памяти - Сайт ритуальных услуг

Современный веб-сайт для компании "Гранит Памяти", специализирующейся на изготовлении памятников и ритуальных услуг. Полнофункциональный интернет-магазин с административной панелью для управления контентом и заказами.

## 🚀 Технологии

### Frontend
- **Next.js 15** (App Router) - React фреймворк с SSR/SSG
- **React 19** - UI библиотека
- **TypeScript** - типизация
- **Material-UI (MUI) v7** - UI компоненты и дизайн-система
- **@mui/x-data-grid** - таблицы данных для админ-панели
- **Emotion** - CSS-in-JS стилизация

### Backend
- **Next.js API Routes** - серверная логика
- **Prisma ORM** - работа с базой данных
- **PostgreSQL** - реляционная база данных
- **JWT (jose)** - аутентификация и авторизация

### Интеграции и утилиты
- **Cloudinary** - облачное хранение изображений (с поддержкой локального хранилища)
- **Yandex Maps** - карты и геолокация
- **pdfmake** - генерация PDF документов
- **xlsx** - экспорт данных в Excel
- **react-snowfall** - декоративные эффекты

## 🛠️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd granit
```

### 2. Установка зависимостей
⚠️ **Важно**: Из-за конфликтов зависимостей используйте флаг `--legacy-peer-deps`:

```bash
npm install --legacy-peer-deps
```

### 3. Настройка переменных окружения
Создайте файл `.env.local` в корне проекта:

```env
# Database
DATABASE_URL="postgresql://username:password@localhost:5432/granit_memory"

# Cloud Storage Configuration
# Варианты: "local" (локальное хранилище в public/uploads) или "cloudinary"
CLOUD_STORAGE_PROVIDER=local

# Cloudinary (рекомендуется для продакшена)
# Заполните только если используете Cloudinary
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# JWT Authentication
# Используйте длинную случайную строку для безопасности
JWT_SECRET=your_super_secret_jwt_key_here_make_it_long_and_random

# Admin Panel Password
# Пароль для доступа к админ-панели
ADMIN_PASSWORD=Oleshuki2012
```

**Важно:** Не коммитьте файл `.env.local` в репозиторий! Он уже должен быть в `.gitignore`.

### 4. Настройка базы данных
```bash
# Создание миграций
npx prisma migrate dev

# Заполнение тестовыми данными
npx prisma db seed
```

### 5. Запуск проекта
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🔐 Доступ к админ-панели

- **URL**: `http://localhost:3000/admin`
- **Пароль**: настраивается через переменную окружения `ADMIN_PASSWORD` (по умолчанию: `Oleshuki2012`)

## 🗄️ Структура базы данных

### Основные модели
- **Product** - товары (памятники) с полями: название, описание, цена, скидки, изображения, SEO, остатки
- **Category** - категории товаров
- **Material** - материалы для изготовления
- **ProductMaterial** - связь товаров и материалов (many-to-many)
- **Tag** - теги для товаров
- **ProductTag** - связь товаров и тегов
- **ProductImage** - множественные изображения товаров
- **ProductVariant** - варианты товаров (размеры, модификации)
- **ProductAttribute** - дополнительные атрибуты товаров
- **RelatedProduct** - связанные товары
- **Order** - заказы с статусами и методами оплаты
- **OrderItem** - позиции заказов
- **User** - пользователи системы
- **ExamplesOurWork** - примеры выполненных работ
- **Content** - настраиваемые контентные блоки (JSON)
- **ContactInfo** - контактная информация

### Особенности БД
- Индексы для оптимизации запросов
- Каскадное удаление связанных записей
- Уникальные ограничения (slug, SKU, email)
- Поддержка децимальных типов для цен
- Timestamps (created_at, updated_at)
- Флаги активности (is_active, is_new, is_popular)

## 🚀 Деплой

### Vercel (рекомендуется)
1. Подключите репозиторий к Vercel
2. Настройте переменные окружения в настройках проекта:
   - `DATABASE_URL` - строка подключения к PostgreSQL
   - `JWT_SECRET` - секретный ключ для JWT
   - `ADMIN_PASSWORD` - пароль админ-панели
   - `CLOUD_STORAGE_PROVIDER` - "cloudinary" или "local"
   - `CLOUDINARY_*` - если используете Cloudinary
3. Настройте PostgreSQL базу данных (например, через Vercel Postgres или внешний провайдер)
4. Запустите миграции: `npx prisma migrate deploy`
5. Деплой происходит автоматически при push в основную ветку

### Важные моменты для продакшена
- Используйте **Cloudinary** для хранения изображений (не локальное хранилище)
- Настройте **надежный JWT_SECRET** (минимум 32 символа)
- Используйте **безопасный пароль** для админ-панели
- Настройте **SSL/HTTPS** для всех соединений
- Регулярно делайте **бэкапы базы данных**

### Другие платформы
Следуйте инструкциям в [PRODUCTION_DEPLOYMENT.md](./PRODUCTION_DEPLOYMENT.md) (если файл существует)

## 🤝 Разработка

### Полезные команды
```bash
# Запуск в режиме разработки (с Turbopack)
npm run dev

# Сборка для продакшена
npm run build

# Запуск продакшен сборки
npm start

# Линтинг кода
npm run lint

# Работа с базой данных
npm run db:generate    # Генерация Prisma Client
npm run db:push        # Применение изменений схемы
npm run db:seed        # Заполнение тестовыми данными
```

### Структура коммитов
- `feat:` - новая функциональность
- `fix:` - исправление багов
- `docs:` - обновление документации
- `style:` - форматирование кода
- `refactor:` - рефакторинг
- `test:` - добавление тестов
- `chore:` - обновление зависимостей, конфигурации

### Требования
- **Node.js** 23.11.1 (управляется через Volta)
- **PostgreSQL** база данных
- **npm** или совместимый менеджер пакетов
