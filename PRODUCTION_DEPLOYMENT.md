# Развертывание на продакшене

## 🚀 Рекомендуемые решения для хранения файлов

### 1. **Cloudinary (Рекомендуется)**
```bash
# Установка
npm install cloudinary

# Переменные окружения
CLOUD_STORAGE_PROVIDER=cloudinary
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

**Преимущества:**
- ✅ Автоматическая оптимизация изображений
- ✅ CDN из коробки
- ✅ Автоматическое сжатие
- ✅ Преобразования изображений
- ✅ Бесплатный тариф до 25GB

### 2. **Локальное хранение (для разработки)**
```bash
# Переменные окружения
CLOUD_STORAGE_PROVIDER=local
```

**Преимущества:**
- ✅ Простота настройки
- ✅ Не требует внешних сервисов
- ✅ Подходит для разработки

## 📋 Пошаговая настройка

### **Шаг 1: Выберите провайдера**
1. **Cloudinary** - для продакшена (рекомендуется)
2. **Local** - для разработки

### **Шаг 2: Настройте переменные окружения**
```bash
# Скопируйте env.example в .env.local
cp env.example .env.local

# Заполните переменные для выбранного провайдера
```

### **Шаг 3: Установите зависимости**
```bash
# Для Cloudinary
npm install cloudinary
```

### **Шаг 4: Настройте CORS (если нужно)**
```javascript
// next.config.js
module.exports = {
  async headers() {
    return [
      {
        source: '/api/upload',
        headers: [
          {
            key: 'Access-Control-Allow-Origin',
            value: process.env.NODE_ENV === 'production' 
              ? 'https://yourdomain.com' 
              : '*',
          },
        ],
      },
    ];
  },
};
```

## 🚀 Быстрый старт с Cloudinary

1. Зарегистрируйтесь на [cloudinary.com](https://cloudinary.com)
2. Получите API ключи из Dashboard
3. Установите переменные окружения:
   ```bash
   CLOUD_STORAGE_PROVIDER=cloudinary
   CLOUDINARY_CLOUD_NAME=your_cloud_name
   CLOUDINARY_API_KEY=your_api_key
   CLOUDINARY_API_SECRET=your_api_secret
   ```
4. Перезапустите приложение

Готово! Теперь файлы будут загружаться в Cloudinary.
