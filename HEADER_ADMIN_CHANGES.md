# Изменения в админ-панели для хедера

## Что было изменено

### 1. Ограничения редактирования хедера
В админ-панели на вкладке "Хедер" теперь можно редактировать только:
- **Текст на плашках с преимуществами** (4 плашки):
  - Качество материалов
  - Индивидуальный подход  
  - Гарантия
  - Надёжность

### 2. Неизменяемые элементы хедера
Следующие элементы хедера **НЕ МОЖНО** изменять через админку:
- Название компании и логотип
- Пункты меню навигации
- Контактная информация
- Дизайн и расположение элементов

### 3. Обновление фронтенда
Компоненты хедера теперь динамически загружают текст плашек из админки:
- `src/components/Header/Header.tsx` - отображает первые 3 плашки
- `src/components/BurgerMenu/BurgerMenu.tsx` - отображает все 4 плашки

## Как это работает

1. **Админка**: Администратор редактирует текст плашек в разделе "Хедер"
2. **API**: Данные сохраняются через `/api/content/about-company`
3. **Фронтенд**: Компоненты хедера загружают данные через `useAboutCompanyContent()`
4. **Отображение**: Плашки автоматически обновляются на сайте

## Технические детали

- Используется существующий хук `useAboutCompanyContent()` из `src/hooks/useContent.ts`
- Данные синхронизируются между секцией "О компании" и хедером
- В хедере показываются первые 3 преимущества (ограничение по дизайну)
- В мобильном меню показываются все 4 преимущества

## Безопасность

Теперь администраторы не могут случайно изменить:
- Структуру навигации
- Контактные данные (редактируются в отдельном разделе)
- Дизайн и макет хедера
- Логотип компании
