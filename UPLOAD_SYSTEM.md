# Система загрузки файлов

## Как работает загрузка изображений

### 1. **Структура папок**
```
public/
  uploads/
    product/     # Изображения товаров
    category/    # Изображения категорий  
    example/     # Изображения примеров работ
```

### 2. **API эндпоинт**
- **URL**: `/api/upload`
- **Метод**: `POST`
- **Параметры**:
  - `file`: Файл изображения
  - `type`: Тип файла (`product`, `category`, `example`)

### 3. **Валидация**
- **Форматы**: JPEG, PNG, WebP
- **Размер**: до 5MB
- **Именование**: `{type}_{timestamp}.{extension}`

### 4. **Возвращаемые данные**
```json
{
  "success": true,
  "fileUrl": "/uploads/product/product_1703123456789.jpg",
  "fileName": "product_1703123456789.jpg"
}
```

### 5. **Использование в компонентах**

#### ImageUpload
```tsx
<ImageUpload
  value={imageUrl}
  onChange={(url) => setImageUrl(url)}
  uploadType="product"  // или "category", "example"
  label="Изображение товара"
  helperText="Загрузите изображение (JPEG, PNG, WebP до 5MB)"
/>
```

### 6. **Преимущества новой системы**

✅ **Производительность**: Файлы хранятся на диске, не в БД  
✅ **Масштабируемость**: Легко добавить CDN  
✅ **Безопасность**: Валидация типов и размеров  
✅ **Организация**: Файлы разделены по типам  
✅ **Кэширование**: Статические файлы кэшируются браузером  

### 7. **Миграция с base64**

Старые base64 изображения будут работать, но новые загрузки будут сохраняться как файлы.

### 8. **Безопасность**

- Валидация MIME типов
- Ограничение размера файлов
- Уникальные имена файлов
- Разделение по типам контента
